# Design Notes — Montaggio Premium Website

## 🎨 Design Philosophy

This website was designed to feel like a **luxury architecture studio** rather than a traditional installation company. Every detail was carefully crafted to exude premium quality and sophistication.

## 🌟 Key Design Decisions

### Color Palette
- **Primary Background**: `#07090D` - Deep, rich black
- **Secondary Background**: `#0F131A` - Subtle dark variation
- **Accent Blue**: `#1F5FBF` - Premium, trust-inspiring blue
- **Accent Hover**: `#3A7DFF` - Brighter, energetic blue
- **Text**: Pure white with zinc variations for hierarchy

This palette creates a **dark luxury aesthetic** similar to high-end automotive or architecture websites.

### Typography
- **Display Font**: Syne - Bold, modern, geometric
- **Body Font**: Inter - Clean, readable, professional
- **Scale**: Dramatically large headings (7xl-9xl) for impact
- **Hierarchy**: Clear contrast between heading sizes

### Spacing & Layout
- **Generous Whitespace**: 32-48 vertical padding on sections
- **Max Width**: 1600px for optimal reading and visual balance
- **Grid Systems**: Asymmetric grids for visual interest
- **Breathing Room**: Nothing feels cramped or compressed

### Photography
- **Large Images**: Every section features prominent photography
- **High Quality**: Professional architecture and interior shots
- **Composition**: Images chosen for luxury, light, and space
- **Treatment**: Subtle gradient overlays for depth

## 🎬 Animation Strategy

### Entrance Animations
- **Hero**: Staggered fade-in with vertical movement
- **Sections**: Scroll-triggered reveals with 100px margin
- **Cards**: Individual delays for cascade effect
- **Images**: Scale and fade combinations

### Interaction Animations
- **Hover States**: Subtle scale (1.02-1.1) for depth
- **Navigation**: Smooth underline growth
- **Buttons**: Scale + shadow increase
- **Images**: Zoom + overlay opacity changes

### Scroll Effects
- **Parallax**: Hero background moves slower than content
- **Opacity**: Hero content fades on scroll
- **Smooth Scroll**: Lenis library for buttery movement
- **Reveal**: Elements appear as they enter viewport

## 📱 Responsive Strategy

### Mobile (<768px)
- Single column layouts
- Reduced font sizes (but still large)
- Hamburger menu
- Stacked cards
- Full-width elements

### Tablet (768px-1024px)
- 2-column grids where appropriate
- Medium font scaling
- Adjusted padding
- Hybrid layouts

### Desktop (>1024px)
- Full multi-column grids
- Maximum font impact
- Complex layouts
- All visual effects

### Large Desktop (>1600px)
- Centered max-width container
- Optimal line lengths
- Enhanced spacing
- Premium feel maintained
