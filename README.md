# Montaggio — Premium Installation Services

A stunning, luxury website for premium installation services featuring modern design, smooth animations, and an exceptional user experience.

## 🎨 Design Features

### Visual Excellence
- **Premium Dark Theme** - Sophisticated color palette (#07090D, #0F131A, #1F5FBF, #3A7DFF)
- **Large Typography** - Bold, impactful headings using Syne and Inter fonts
- **Breathtaking Hero** - Full-screen hero with parallax effects and gradient overlays
- **Architecture Magazine Feel** - Large, high-quality photography throughout
- **Generous Spacing** - Ample whitespace for a luxury aesthetic

### Advanced Animations
- **Framer Motion** - Smooth scroll-triggered animations
- **Parallax Effects** - Dynamic background movement on scroll
- **Hover Interactions** - Premium card and image hover states
- **Fade & Scale Reveals** - Elegant content entrance animations
- **Smooth Scrolling** - Lenis for buttery-smooth scroll experience

```bash
# Build for production
npm run build
```
